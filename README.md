# RoundUp

![RoundUp](assets/RoundUp-logo.svg)

**RoundUp** — настільний інструмент об'їздів, фото, GPS-точок і контролю охоплення територій.

## Поточний стан

- ✅ Графічний Windows-лаунчер із брендингом RoundUp і перевіркою оновлень через публічні GitHub Releases.
- ✅ Підготовлений **однофайловий інсталятор** `RoundUpSetup-win-x64.exe` (Inno Setup, без прав адміністратора), збірка та smoke-тест на Windows через GitHub Actions.
- ✅ Особисті дані зберігаються локально у `%LOCALAPPDATA%\\RoundUp`, окремо від оновлюваної програми.
- ✅ SHA-256 перевірка оновлень, резервна копія старої збірки та відкат програми при збої встановлення.
- ⏳ **Сам інтерпретатор ще не доданий до репозиторію.** Наявний тестовий інсталятор — не готовий RoundUp з картою. Старий GeoZamir 5.5 не перейменовано всередині застосунку; зміни імпорту коментарів і геоданих та малювання охоплених секторів також потребують вихідного коду.

## Як працюватиме встановлення

1. Один раз завантажуєте `RoundUpSetup-win-x64.exe` з [Releases](https://github.com/lyesm1th/RoundUp/releases).
2. Інсталятор ставить `RoundUpLauncher.exe`, робить ярлик RoundUp.
3. Лаунчер перевіряє останній повний реліз, пропонує **Встановити / Оновити / Запустити**.
4. Нові релізи замінюють лише `app`; ваші проєкти й фото залишаються у власних папках.

Перш ніж поширювати програму як робочу, потрібно додати до репозиторію **виправлений і перебрендований інтерпретатор**.

## Локальні папки

| Каталог | Призначення |
| --- | --- |
| `%LOCALAPPDATA%\\RoundUp\\app` | Поточна програма |
| `%LOCALAPPDATA%\\RoundUp\\projects` | Проєкти та їхні власні дані |
| `%LOCALAPPDATA%\\RoundUp\\photos` | Фотографії |
| `%LOCALAPPDATA%\\RoundUp\\imports` | Локальні вхідні архіви |
| `%LOCALAPPDATA%\\RoundUp\\backups\\app` | Попередні версії програми |
| `%LOCALAPPDATA%\\RoundUp\\backups\\projects` | Місце для резервних копій проєктів |
| `%LOCALAPPDATA%\\RoundUp\\updates` | Тимчасове завантаження оновлень |
| `%LOCALAPPDATA%\\RoundUp\\logs` | Журнал проблем лаунчера |

**Важливо:** створення папки `backups/projects` не означає, що резервне копіювання проєктів уже підключено до інтерпретатора; це буде інтегровано під час перенесення його вихідного коду.

## Збірка

Публічний workflow [Build RoundUp for Windows](.github/workflows/windows.yml) створює та тестує `RoundUpLauncher.exe` і `RoundUpSetup-win-x64.exe`. Для повного релізу потрібен застосунок у `app/RoundUp.exe`; можливий тимчасовий імпорт з legacy ZIP, але просте перейменування `.exe` **не змінює** назви, графіку й помилки у старому застосунку.

Справний повний реліз `vX.Y.Z` міститиме:

- `RoundUpSetup-win-x64.exe` — встановлення одним файлом;
- `RoundUpLauncher.exe` — окремий портативний лаунчер;
- `RoundUp-App-win-x64.zip` — програмний пакет;
- `roundup-update.json` — номер версії та перевірна сума пакета.

⚠️ Не додавайте до публічного репозиторію приватні архіви об'їздів, фото клієнтів, робочі бази, паролі чи документи. Потрібні лише вихідні файли програми / чиста її збірка.
