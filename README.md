# RoundUp

![RoundUp](assets/RoundUp-logo.svg)

**RoundUp** — Windows-програма для ведення об'їздів, фотографій, геоміток, проєктів та карти охоплення територій.

## Що вже зроблено

- Самостійний графічний лаунчер `RoundUpLauncher.exe` (Windows x64).
- Під час запуску відображає актуальну/встановлену версію та кнопки «Оновити RoundUp» / «Запустити RoundUp».
- Створює у `%LOCALAPPDATA%\\RoundUp` папки `app`, `projects`, `photos`, `imports`, `updates`, `backups`, `logs`.
- Створює ярлик на робочому столі, не закриваючи стартове вікно.
- Завантажує релізи з `lyesm1th/RoundUp`, перевіряє SHA-256 перед встановленням.
- Зберігає попередню версію самої програми в `backups/app` на випадок відкату. Не перезаписує папки з проєктами та фотографіями.
- Веде діагностичний журнал у `%LOCALAPPDATA%\\RoundUp\\logs\\launcher.log`.
- GitHub Actions збирає GUI та перевіряє появу вікна на Windows. Під час тесту дані користувача не потрібні.

## Стан

**Графічний лаунчер збирається й пройшов тест запуску на Windows. Сам інтерпретатор GeoZamir 5.5 поки не імпортований у цей репозиторій, тому інсталяційного релізу з програмою ще немає.** Не плутайте тестовий GitHub Actions artifact з готовим релізом.

## Перенесення старої програми

Для першого релізу потрібно додати готовий файл `app/RoundUp.exe`. Або завантажити в корінь репозиторію попередній архів `GeoZamir_5.5_GUI_Launcher_Windows.zip`: workflow розпакує його, знайде основний EXE (не launcher) і підготує пакет програми. Для подальших виправлень потрібні також вихідні файли інтерпретатора.

Після цього випуск створюється тегом `vX.Y.Z`. Workflow додає:
- `RoundUpLauncher.exe` — графічний лаунчер;
- `RoundUp-App-win-x64.zip` — програма;
- `roundup-update.json` — версія та SHA-256 пакета.

Публічний GitHub Releases забезпечує анонімні оновлення. Жодні паролі або персональні токени GitHub у лаунчері не зберігаються.

**Не завантажуйте в GitHub архіви об'їздів, фотографії клієнтів, робочі бази чи приватні документи.** Вони повинні залишатися локально. Папки та резервні копії проєктів будуть повністю інтегровані із самим інтерпретатором після перенесення його коду.
