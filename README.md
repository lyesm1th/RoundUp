# RoundUp

Windows-застосунок для картографування об'їздів та обстежених територій.

## Стан проєкту

Цей репозиторій поки містить інфраструктуру лаунчера та CI. Вихідні файли інтерпретатора GeoZamir 5.5 **ще не перенесено** з архіву ChatGPT, тому це не повна збірка RoundUp.

## Як працює лаунчер

- Після першого запуску `RoundUpLauncher.exe` встановлюється в `%LOCALAPPDATA%\RoundUp` і створює ярлик на робочому столі.
- `app` — бінарні файли програми; `projects`, `photos`, `imports` — дані користувача; `backups` — резервні копії; `updates` — завантаження.
- При запуску перевіряє GitHub Releases, пропонує **Оновити** або **Запустити**.
- Перевіряє SHA-256 пакета перед встановленням, зберігає попередню версію програми для відкату. Користувацькі дані не перезаписує.

## Налаштування публічних оновлень

Поточний GitHub-репозиторій `lyesm1th/RoundUp` **приватний**. Releases у приватному репозиторії не доступні лаунчеру без автентифікації. Не вбудовуйте GitHub PAT в EXE. Для безкоштовного безпечного автооновлення публікуйте **тільки готові релізи** у публічному репозиторії оновлень і змініть `ReleaseRepository` у коді лаунчера на його адресу. Вихідний код можна залишити тут приватним.

## Збірка

Використовується GitHub Actions із Windows runner. На кожному push збирається `RoundUpLauncher.exe` та публікується artifact. Реліз програми за тегом `v*` можливий тільки після додавання готової програми в `app/RoundUp.exe` (з необхідними залежностями). Тоді workflow створить `RoundUp-App-win-x64.zip` та `roundup-update.json` із SHA-256.

Не додавайте в Git репозиторій реальні проєкти, приватні ZIP-архіви об'їздів, фото та файли із персональними даними.
