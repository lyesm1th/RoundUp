# RoundUp

![RoundUp](assets/RoundUp-logo.svg)

**RoundUp** — карта об’їздів, фото, GPS-точок і контроль фактичного охоплення територій для Windows.

## Встановлення для Windows

1. Відкрийте [Releases](https://github.com/lyesm1th/RoundUp/releases/latest).
2. Один раз завантажте **RoundUpSetup-win-x64.exe** і запустіть.
3. На робочому столі з’явиться ярлик **RoundUp**. Відкрийте його.
4. Лаунчер автоматично перевірить GitHub. При першому запуску натисніть **«Встановити RoundUp»**, після завантаження — **«Запустити RoundUp»**.
5. Надалі запускайте той самий ярлик. За наявності нової версії натисніть **«Оновити RoundUp»**. Перевстановлювати програму не потрібно.

Інсталятор не потребує прав адміністратора. Для першого завантаження ядра й подальших оновлень потрібен інтернет. Встановлена програма працює з локальними даними, навіть якщо GitHub тимчасово недоступний.

### Що входить у версію 6.0

- **RoundUpLauncher.exe** — окреме графічне вікно з логотипом, поточною та доступною версією, кнопкою встановлення / оновлення / запуску.
- **RoundUp.exe** — сучасна оболонка браузерного інтерпретатора; перевірене оригінальне ядро GeoZamir 5.5 використовується всередині для імпорту, зберігання, відображення карти й фотографій.
- Новий дизайн із назвою **RoundUp**, власною іконкою та адаптивним розміщенням.
- **Охоплення ділянки** — окреслення довільної території на карті, навіть якщо немає об’єктів чи фотографій.
- **Охоплення секторами** — відмітки приблизно кілометрових географічних комірок; повторний клік знімає відмітку.
- Показ приблизної площі відмічених територій, кількості контурів і секторів. При перекритті площі можуть підсумовуватися повторно; це орієнтовна оцінка, не геодезичний розрахунок.
- Ділянки й сектори автоматично зберігаються **окремо для кожного проєкту**.
- Розширене розпізнавання JSON-полів GPS та коментарів із польових ZIP-звітів (у тому числі вкладені координати, GeoJSON, підписи до фото).
- Оновлення через GitHub Releases із перевіркою SHA-256 перед встановленням. Стара версія програми зберігається для відкату.

> Відображення й повторне збереження даних конкретного архіву залежить від його фактичного формату. Синтетичні тести охоплюють типові структури GPS/коментарів, але не замінюють перевірку всіх реальних архівів RoadUp.

## Де зберігаються дані

Програма сама створює папку **%LOCALAPPDATA%\RoundUp**:

| Папка | Що в ній |
| --- | --- |
| `app` | Програма, яка оновлюється |
| `projects\workspace` | Дані та база оригінального інтерпретатора |
| `projects\coverage` | Контури й сектори обстеження кожного проєкту |
| `photos`, `imports` | Особисті папки для фото та імпортів |
| `backups\app` | Попередні версії програми |
| `backups\projects` | Каталог резервних копій проєктів |
| `logs` | Журнал запусків і помилок |

Дані **не завантажуються до GitHub**. Оновлюється лише папка `app`, а `projects`, `photos`, `imports` та `backups` залишаються. Для ручного резервування проєкту використовуйте пункт меню **«Зберегти проєкт (копія)»**. Позначені геозони додатково зберігаються у `projects/coverage` — скопіюйте цю папку разом із резервною копією, якщо переносите проєкти на інший комп’ютер.

## Як позначати обстежену територію

1. Відкрийте потрібний проєкт.
2. На карті натисніть **«Ділянка»**, послідовно позначте точки контуру. Завершіть подвійним кліком або Enter.
3. Або натисніть **«Сектори»** і клацайте комірки, які фактично оглянули.
4. Натисніть **«Готово»**. Обстежені частини відображатимуться після повторного відкриття програми.

Позначення секторів не залежать від наявності фото. Якщо потрібно показувати **відсоток виконання плану**, окремо задайте межі планової території — без планового контуру відсоток був би неточним.

## Для розробки

Код C# (Windows launcher + local host) та інтерфейс JS/CSS знаходяться в `src/`. Windows CI:

- перевіряє синтаксис JavaScript і розпізнавання GPS/коментарів;
- компілює самодостатній `RoundUp.exe` і `RoundUpLauncher.exe`;
- запускає справжнє ядро інтерпретатора на Windows;
- перевіряє локальну сторінку, токен, файли UI та збереження геозон;
- збирає Inno Setup і тестує інсталяцію без діалогів;
- запаковує `RoundUp-App-win-x64.zip` та SHA-256 маніфест для наступних автоматичних оновлень.

**Безпека:** не додавайте у публічний репозиторій приватні архіви об’їздів, фотографії клієнтів, бази, паролі та ключі. Мережева синхронізація й адміністраторські/менеджерські облікові записи на цьому етапі не підключені.
